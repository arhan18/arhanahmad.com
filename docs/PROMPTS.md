# Prompts for Subtitly Logo & Preview Images

## Subtitly Logo Prompt

```
Create a modern, minimalist logo for "Subtitly" - an AI-powered subtitle generation tool.

Design requirements:
- Clean, geometric icon mark
- Should work at small sizes (favicon) and large sizes
- Colors: Deep purple (#7c3aed) to cyan (#06b6d4) gradient
- Include subtle video/subtitle visual metaphor
- No text in the icon, just the symbol
- Style: Modern SaaS, tech startup aesthetic

Concept directions:
1. A play button with subtitle lines flowing from it
2. A speech bubble with waveform/sound lines
3. A screen/monitor with text lines appearing
4. Abstract "S" shape formed by subtitle text lines

Output: SVG format, transparent background
```

## ToolboxImage Preview Image Prompt

```
Create a compelling preview/thumbnail image for "ToolboxImage" - an AI-powered image toolbox.

Design requirements:
- Size: 1200x630px (OG image standard)
- Show the tool in action: image editing, resizing, compression
- Dark background with vibrant accent colors (cyan, purple)
- Include visual elements: image icons, tools, AI sparkles
- Text overlay: "AI Image Toolbox" in bold, modern font
- Style: Clean, professional, tech-forward

Visual elements to include:
- Multiple image thumbnails/cards being processed
- Tool icons (crop, resize, compress)
- AI/automation visual cues (sparkles, gears)
- Modern glassmorphism or neumorphism effects

Color palette: #06b6d4 (cyan), #8b5cf6 (purple), #1a1a2e (dark bg)
```

## How to Use These Prompts

### For Logo:
1. Use Midjourney, DALL-E, or Stable Diffusion
2. Generate multiple variations
3. Pick the cleanest one
4. Export as SVG (may need to trace in Illustrator/Figma)

### For Preview Images:
1. Use Canva, Figma, or Photoshop
2. Follow the visual direction from prompts
3. Ensure text is readable at small sizes
4. Test on dark and light backgrounds

## Quick Canva Template Approach

If you want to create these quickly:

1. **Go to Canva** → Create custom design 1200x630
2. **Use dark background** (#1a1a2e)
3. **Add product name** in bold white text
4. **Add tagline** in smaller text
5. **Add relevant icons** from Canva's library
6. **Add gradient accent** (cyan to purple)
7. **Export as PNG**

This is faster than AI generation and gives you more control.
